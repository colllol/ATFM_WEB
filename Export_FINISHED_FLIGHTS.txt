tu Oracle nguon sang T_FINISHED_FLIGHTS tren Oracle dich qua schema tam
ATFM_STAGE. Quy trinh khong xoa du lieu dang co tren schema ATFM.

BUOC 7 - CHUAN HOA ISACCEPTED VA KIEM TRA TAP STAGING
-----------------------------

7.0. Xu ly chenh lech schema ISACCEPTED:

Kiem tra column tren staging:

SELECT column_name, data_type, nullable, data_default
FROM all_tab_columns
WHERE owner = 'ATFM_STAGE'
  AND table_name = 'T_FINISHED_FLIGHTS'
  AND column_name = 'ISACCEPTED';

Neu khong co cot ISACCEPTED (truong hop dump nguon cu), them cot vao staging
voi gia tri 1. Day la du lieu da ket thuc va se duoc danh dau da chap nhan
khi nap vao bang dich:

    ADD (ISACCEPTED NUMBER(1) DEFAULT 1 NOT NULL);

Neu cot da ton tai, cap nhat cac dong import ve 1 theo quy tac nghiep vu
finished flights. Khong sua bang nguon:

UPDATE ATFM_STAGE.T_FINISHED_FLIGHTS
   SET ISACCEPTED = 1
 WHERE ISACCEPTED IS NULL
    OR ISACCEPTED <> 1;

ALTER TABLE ATFM_STAGE.T_FINISHED_FLIGHTS
    MODIFY (ISACCEPTED DEFAULT 1 NOT NULL);

COMMIT;

Kiem tra kieu du lieu va gia tri:

SELECT ISACCEPTED, COUNT(*) AS row_count
FROM ATFM_STAGE.T_FINISHED_FLIGHTS
GROUP BY ISACCEPTED
ORDER BY ISACCEPTED;

Tat ca dong trong tap import phai co ISACCEPTED = 1. Neu muon bao toan
trang thai 0/1 tu nguon thay vi danh dau 1, phai bo sung phuong an nghiep vu
va cap nhat dieu kien conflict truoc khi tiep tuc.

WHERE FLIGHTDATE >= DATE '2026-07-01'
  AND FLIGHTDATE <  DATE '2026-08-01'
GROUP BY FLIGHT_ID
HAVING COUNT(*) > 1;

Khong duoc co dong nao. Neu ID khong phai khoa duy nhat, dung khoa P/U da
xac dinh tai Buoc 1.3.

11.4. Doi chieu mau du lieu:

SELECT s.FLIGHT_ID,
       s.FLIGHT_PK,
       s.PERM_ID,
       s.FLIGHTDATE,
       s.FLIGHTNBR,
       s.FROM_AIRP,
       s.TO_AIRP,
       s.ETD,
       s.ETA,
       s.ISACCEPTED
FROM ATFM_STAGE.T_FINISHED_FLIGHTS s
WHERE ROWNUM <= 20
ORDER BY s.FLIGHTDATE, s.FLIGHT_ID;

Chon mot so FLIGHT_ID tren va truy van lai ATFM.T_FINISHED_FLIGHTS, bao dam
FLIGHTDATE/FLIGHTNBR/FROM_AIRP/TO_AIRP/ETD/ETA/ISACCEPTED khop.

11.5. Kiem tra object invalid sau import:

SELECT object_name, object_type, status
FROM dba_objects
WHERE owner = 'ATFM'
  AND status <> 'VALID'
  AND object_name LIKE '%FINISHED%'
ORDER BY object_type, object_name;


BUOC 12 - DUNG KHAN CAP, ROLLBACK VA DON DEP
---------------------------------------------

Dung ngay quy trinh neu:

- Checksum khong khop hoac export/import log co ORA nghiem trong.
- Stage count khong bang source count, co row ngoai pham vi hoac FLIGHT_ID trung.
- TARGET_JULY_COUNT khac 0 ma chua co phuong an merge duoc phe duyet.
- Import APPEND loi, missing_after_import khac 0 hoac phat sinh duplicate.
- Trigger/constraint bi invalid hoac ung dung hien thi sai lich.

Khong tu dong xoa du lieu de rollback khi co job khac da ghi vao bang sau
import. Bao toan dump/log va phoi hop DBA xac dinh tap FLIGHT_ID can xu ly. Chi khi
co xac nhan rang tap import la duy nhat va khong co ghi chen, DBA moi xem
xet lenh rollback theo FLIGHT_ID staging, vi du:

-- CHI LA MAU; KHONG CHAY NEU CHUA CO PHE DUYET:
-- DELETE FROM ATFM.T_FINISHED_FLIGHTS t
-- WHERE EXISTS
--       (SELECT 1 FROM ATFM_STAGE.T_FINISHED_FLIGHTS s
--        WHERE s.FLIGHT_ID = t.FLIGHT_ID);
-- COMMIT;

Giu toi thieu cac file:

Sau nghiem thu va duoc phep don dep:

SELECT COUNT(*) FROM ATFM_STAGE.T_FINISHED_FLIGHTS;

PHU LUC A - CAC CAU LENH KIEM TRA NHANH
----------------------------------------

Nguon:

SELECT COUNT(*) AS source_count
FROM T_FINISHED_FLIGHTS
WHERE FLIGHTDATE >= DATE '2026-07-01'
  AND FLIGHTDATE <  DATE '2026-08-01';

Staging:

SELECT COUNT(*) AS stage_count,
       SUM(CASE WHEN FLIGHTDATE IS NULL THEN 1 ELSE 0 END) AS null_date_count,
       SUM(CASE WHEN FLIGHTDATE < DATE '2026-07-01'
                  OR FLIGHTDATE >= DATE '2026-08-01' THEN 1 ELSE 0 END)
           AS out_of_range_count
FROM ATFM_STAGE.T_FINISHED_FLIGHTS;

Dich:

SELECT COUNT(*) AS target_count,
       SUM(CASE WHEN FLIGHT_ID IS NULL THEN 1 ELSE 0 END) AS null_flight_id_count
FROM ATFM.T_FINISHED_FLIGHTS
WHERE FLIGHTDATE >= DATE '2026-07-01'
  AND FLIGHTDATE <  DATE '2026-08-01';

Kiem tra xung dot FLIGHT_ID truoc APPEND:

SELECT COUNT(*) AS conflict_count
FROM ATFM_STAGE.T_FINISHED_FLIGHTS s
JOIN ATFM.T_FINISHED_FLIGHTS t
  ON t.FLIGHT_ID = s.FLIGHT_ID;
